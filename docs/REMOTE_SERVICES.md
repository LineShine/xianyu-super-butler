# 远程接口使用说明

核查日期：2026-10-20（北京时间）。

本次将本地 `yutaixian-pro` 中的风控页服务说明、Token 服务入口和前后端防误填校验迁入当前项目。已有调用协议、测试、保存、日志和容量控制逻辑保持当前项目实现；没有导入原项目账号数据、密钥或远程配置，没有启用远程调用。

## 两套服务分别配置

| 项目 | 风控页：远程过滑块 | 系统设置：远程获取 Token |
| --- | --- | --- |
| 配置位置 | 风控日志 → 展开远程过滑块配置 | 系统设置 → 基础设置 → Token获取方式 → 远程接口 |
| 原项目给出的 URL | `https://xy-api.zhinianboke.com/api/v1/captcha/slider-solve` | `https://api.xianyushop.shop/api/external/invoke` |
| 密钥来源 | 在 `https://xy.zhinianboke.com` 注册、登录后，从个人设置获取该站用户密钥 | 在 `https://api.xianyushop.shop` 注册、登录，在接口列表中查看“闲鱼获取Token”接口和对应密钥 |
| 实际发送数据 | 用户密钥、账号标识、滑块验证链接、超时参数；仅开启“传递账号 Cookie”后附加完整 Cookie 和设备标识 | API 密钥及对应账号的完整 Cookie |
| 密钥传递方式 | JSON 请求体 `secret_key` | 请求头 `X-API-Key` |
| 测试行为 | 发送空验证链接，检测连通性和密钥；`punish 链接不能为空` 表示已通过此前的密钥校验 | 发送空 Cookie，检测连通性和响应格式 |

两套地址和密钥不可混填。原项目的完整 URL 是填写示例，不会自动写入当前配置；也支持自行部署的兼容服务。

## 使用步骤

### 风控页的远程过滑块

1. 在服务方网站注册、登录，取得该站「个人设置」中的密钥。
2. 在当前项目的「风控日志」展开配置，填写上述滑块接口 URL 和服务方密钥。
3. 点击「测试」，通过后再「保存」。测试通过只说明连通性及密钥通过对应检查，不代表实际滑块一定成功。
4. “调用远程接口时传递账号 Cookie”默认关闭，建议保持关闭，除非已了解并接受服务方的数据处理方式。
5. “禁止远程调用本机过滑块接口”限制其他系统调用你这台机器，不是你调用第三方的开关，无需为了使用第三方而关闭。
6. 当前系统对风险账号的暂停仍然有效。先处理闲鱼 App 中的安全验证，再在账号管理中手动启用。

### 远程获取 Token

1. 在 Token 服务平台取得“闲鱼获取Token”接口的密钥。
2. 在「系统设置 → 基础设置 → Token获取方式」选「远程接口」。
3. 填写 Token URL 和密钥，点击「测试远程接口」，再点击「保存远程接口」。
4. 该设置是全局配置，各账号后续无有效缓存时会使用它。只选择下拉框不会完成首次远程配置，需保存。
5. 风控页的“不传 Cookie”开关不作用于此接口；实际取 Token 始终发送完整 Cookie。

## 收费核查

- 已通过浏览器实际打开上述两个服务网站的公开页面。
- Token 平台需要注册、登录；公开登录与注册页没有显示本接口的单价、扣费方式、失败是否收费或退款规则。
- 远程过滑块服务的网站公开介绍也未提供可核实的本接口费率。本地原项目的 `slider-solve` 路由只有密钥校验和容量控制，没有直接扣费逻辑，但这不能证明线上第三方免费。
- 因此，目前不能确认单次费用、套餐价格或免费额度。应在服务方登录后的接口说明/费率页面确认；若没有明示，应向服务方确认。
- 购买前应确认：成功或请求即扣费、失败/重试是否扣费、测试是否扣费、每次价格、最低充值及退款规则。网站的账号续期/激活码价格不等同于接口调用费。
- 本次没有注册商家账号、充值、购买或发送实际闲鱼 Cookie。

## 安全判断

不能仅凭源码有入口、使用 HTTPS 或接口测试成功，就认定第三方安全，也不能保证使用后不触发闲鱼风控。

远程 Token 服务会收到完整登录 Cookie，存在账号会话被滥用的风险。远程过滑块在关闭 Cookie 传递时发送的数据较少，但验证链接和账号标识仍属于敏感会话相关数据。

本次没有取得可验证的第三方数据保留、删除承诺或独立安全审计证据。原界面的“远程系统不会保存该值”不能由本地代码保证，已改成如实说明由服务方决定数据留存；滑块密钥输入已改为遮罩显示。

当前没有替你启用任一第三方服务。连续三次失败暂停、账号隔离、顶部风险提示及原有红色提示均保留。密钥应直接填写在本地配置页，不要放入聊天、截图或公开日志。
